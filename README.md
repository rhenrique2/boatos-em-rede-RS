# boatos-em-rede-RS
centenas de eleitores-agentes conectados numa rede social, trocando uma notícia falsa. Cada agente segue regras simples (acreditar ou não, compartilhar ou não, checar ou não). Ninguém controla o todo, mas, ao rodar a simulação, aparece um comportamento coletivo: o boato viraliza ou morre.
